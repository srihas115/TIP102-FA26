## About This Repository

This repository will hold my problem sets, solution files, notes, and course reference material for **TIP102: Intermediate Technical Interview Prep**, Fall 2026 section on [CodePath.org](https://www.codepath.org). All solution files will be written in **Python**.

## File Naming

When adding problems, use the same pattern from TIP101:

```text

Unit ##/Session #/Version #/NN_problem_slug.py
```

Every `.py` solution file should have a matching `.md` file with the same name in the same folder.
